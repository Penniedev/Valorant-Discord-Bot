# Valorant Discord Bot

A comprehensive Discord bot that provides Valorant statistics and match history for players. The bot allows users to look up their own stats and compare performance with friends by simply providing their Riot ID (username#tag).

## 🎯 Features

- **Match History Lookup** - Detailed statistics from recent matches
- **Performance Tracking** - Monitor your improvement over time with trends
- **Rank Progression** - Track your competitive rank journey
- **Agent Performance Analytics** - See which agents you perform best with
- **Match Outcome Summaries** - Quick overviews of your recent games

## 🔧 Technical Details

The bot uses the **Riot Games API** to fetch player data, match history, and competitive updates. It's designed to help players track their improvement over time and provide quick access to their Valorant statistics directly within Discord servers.

### APIs Used
- **Account** - Player identification and basic info
- **Match** - Match history and detailed statistics  
- **Competitive** - Rank and competitive data

## 👥 Target Audience

Valorant players who want to easily access their game statistics and share their progress with friends in Discord communities.

## 🚀 Getting Started

Simply invite the bot to your Discord server and use commands like:
- `/valstats username#tag` - Get player statistics
- `/valmatches username#tag` - View recent match history
- `/valrank username#tag` - Check current rank and progression
